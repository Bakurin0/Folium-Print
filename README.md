# Folium-Print
O Folium Print é uma aplicação desktop ágil para criar e imprimir etiquetas e documentos com modelos predefinidos. Basta preencher o formulário, pré-visualizar em tempo real e imprimir direto em folhas A4 ou impressoras térmicas com calibração milimétrica e suporte nativo a códigos de barras e QR Codes. Rápido, leve e sem complicação visual.
